# Host Requirements — что нужно хосту помимо скиллов

Гримуар — источник истины **по скиллам**. Этот файл — источник истины
**по остальному**, что нужно живому хосту. Ничего из перечисленного
`install-v2.sh` не ставит автоматически.

Проверено на хосте: Linux, x86_64, Debian/Ubuntu, Hermes Agent.

## Обязательное

| Что | Версия | Как ставится | Зачем |
|-----|--------|--------------|-------|
| `bash` | 4.4+ | системный | все скрипты гримуара |
| `git` | 2.30+ | `apt install git` | клонирование гримуара |
| `python3` | 3.9+ | `apt install python3` | hermes CLI |
| `rsync` | любой | `apt install rsync` | обновление скиллов по контенту; без него install-v2 работает, но медленнее (`diff -rq` на каждый скилл) |
| Hermes Agent | — | см. документацию hermes-agent | рантайм, в котором живут скиллы |

Без `rsync` установщик не падает — он переключается на `diff -rq` + `cp -rf`.
Это медленнее на ~900 скиллах, но корректно.

## Внешние бинарники, которые скиллы ожидают на PATH

Эти **не** входят в гримуар. Скилл, которому нужен бинарь, без него
не работает — молча или с внятной ошибкой.

| Бинарь | Нужен скиллам | Установка |
|--------|---------------|-----------|
| `moli` | `moli-webfetch`, `moli-websearch`, `moli-cdp-server` | установщик из репозитория lexmount/moli, кладёт в `~/.local/bin/moli` |
| `node` | CDP-автоматизация, часть web-скиллов | системный пакет |

Проверка `moli` (важно: релиз **не публикует checksum-файл**, единственная
проверка целостности — ручное сравнение SHA-256 с официальным артефактом):

```bash
curl -sL https://github.com/lexmount/moli/releases/latest/download/moli-x86_64-unknown-linux-gnu.tar.gz -o /tmp/m.tar.gz
tar xzf /tmp/m.tar.gz -C /tmp/ && sha256sum /tmp/moli-*/moli
sha256sum ~/.local/bin/moli     # значения должны совпасть
```

`playwright` и `puppeteer` (нужны для `moli-cdp-server` в связке с клиентом)
в гримуар **не** входят и на проверенном хосте **не установлены**.

## Что гримуар НЕ хранит (осознанно)

- **Секреты.** API-ключи провайдеров, токены Telegram-ботов, credentials.
  Проверено: в tracked-файлах гримуара секретов нет. Хранить их в git —
  нельзя, отсюда и отсутствие.
- **`~/.hermes/config.yaml`.** Живой конфиг хоста. В гримуаре лежит только
  шаблон `en/configs/hermes-config.yaml` + `hermes-env.template`.
- **Memories, cron-задачи, состояние сессий.** Этоruntime-состояние, а не
  библиотека. Копируется отдельно, если нужно, вручную.

## Сетевые требования

- **Tor-прокси в env ломает `git clone`** — клонирование зависает (проверено:
  таймаут 180 с). `install-v2.sh` снимает `*_proxy` перед клоном. Если
  клонируешь руками — оборачивай в `env -u http_proxy -u https_proxy
  -u ALL_PROXY -u all_proxy`.
- `moli fetch` через Tor работает, но медленнее.
- Открывать: `github.com` (клон/пуш), `raw.githubusercontent.com`
  (bootstrap по HTTPS), плюс сами целевые сайты.

## Проверка хоста после установки

```bash
bash en/scripts/verify-grimoire.sh      # полная проверка, exit 0 = готово
hermes skills list                      # что видит рантайм
```

`verify-grimoire.sh` клонирует гримуар во временный каталог, прогоняет
установку на изолированный `--target`, сверяет количество скиллов и хеши,
и **падает с ненулевым кодом**, если хост разошёлся с гримуаром.
