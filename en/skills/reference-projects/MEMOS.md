# MemOS — Memory OS for AI Systems (MemTensor, 10.5k★)

**Официальный локальный memory-плагин для Hermes Agent и OpenClaw.**

## Суть
Самоэволюционирующая память: L1 traces → L2 policies → L3 world models → crystallized Skills.
Local-first (SQLite, ничего не уходит с машины), hybrid retrieval (FTS5 + vector), dedup, multi-agent.

## Установка (Linux, локальный плагин)
```bash
curl -fsSL https://raw.githubusercontent.com/MemTensor/MemOS/main/apps/memos-local-plugin/install.sh | bash
```

## Зачем нам
Прямой апгрейд «ничего не забудешь» — самоэволюционирующая память поверх Hermes.
Плюс viewer-дашборд для просмотра памяти.
