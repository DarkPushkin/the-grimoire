# bip39 1.0.6 API Reference (from pub cache)

## Key Functions

### entropyToMnemonic
```dart
String entropyToMnemonic(String entropyString)
```
**Changed:** Now takes a **hex string**, not `Uint8List`.
- Input: hex-encoded entropy (e.g., "a1b2c3d4...")
- Output: BIP39 mnemonic phrase (space-separated words)

```dart
import 'package:convert/convert.dart' as hex;

// Old (pre-1.x)
final entropy = Uint8List(32); // 32 bytes = 256 bits = 24 words
final mnemonic = bip39.entropyToMnemonic(entropy);

// New (1.x)
final entropyBytes = Uint8List(32);
final entropyHex = hex.encode(entropyBytes);  // Convert to hex string
final mnemonic = bip39.entropyToMnemonic(entropyHex);
```

### mnemonicToSeed
```dart
Uint8List mnemonicToSeed(String mnemonic, {String passphrase = ''})
```
- Unchanged: returns `Uint8List` (64 bytes = 512 bits)
- Passphrase defaults to empty string

### validateMnemonic
```dart
bool validateMnemonic(String mnemonic)
```
- Validates word count (12/15/18/21/24) and checksum
- Returns `bool`

### generateMnemonic
```dart
String generateMnemonic({int strength = 128, RandomBytes randomBytes = _randomBytes})
```
- Generates mnemonic from random entropy
- `strength` in bits (128/160/192/224/256) — maps to 12/15/18/21/24 words

## Entropy ↔ Mnemonic Mapping

| Entropy Bits | Entropy Bytes | Mnemonic Words | Checksum Bits |
|--------------|---------------|----------------|---------------|
| 128          | 16            | 12             | 4             |
| 160          | 20            | 15             | 5             |
| 192          | 24            | 18             | 6             |
| 224          | 28            | 21             | 7             |
| 256          | 32            | 24             | 8             |

Formula: `words = (entropy_bits + checksum_bits) / 11` where `checksum_bits = entropy_bits / 32`

## Example: Generate 24-word Mnemonic
```dart
import 'package:bip39/bip39.dart' as bip39;
import 'package:convert/convert.dart' as hex;
import 'dart:math' show Random;

final random = Random.secure();
final entropyBytes = Uint8List.fromList(List.generate(32, (_) => random.nextInt(256)));
final entropyHex = hex.encode(entropyBytes);
final mnemonic = bip39.entropyToMnemonic(entropyHex);
// mnemonic is now a 24-word BIP39 phrase
```

## Example: Verify Mnemonic
```dart
import 'package:bip39/bip39.dart' as bip39;

bool isValid = bip39.validateMnemonic(mnemonic);
if (!isValid) throw ArgumentError('Invalid BIP39 mnemonic');

final seed = bip39.mnemonicToSeed(mnemonic, passphrase: 'optional passphrase');
// seed is Uint8List(64) - use for BIP32/44 derivation
```

## Common Errors

| Error | Cause | Fix |
|-------|-------|-----|
| `Argument type 'Uint8List' can't be assigned to 'String'` | Passing bytes to `entropyToMnemonic` | Convert to hex: `hex.encode(bytes)` |
| `Invalid entropy` | Wrong entropy length | Use 16/20/24/28/32 bytes only |
| `Invalid mnemonic` | Checksum mismatch or invalid words | Re-check wordlist and word count |

## Integration with bip32/ed25519_hd_key
```dart
import 'package:bip39/bip39.dart' as bip39;
import 'package:ed25519_hd_key/ed25519_hd_key.dart' as ed25519_hd_key;
import 'package:convert/convert.dart' as hex;

final mnemonic = "abandon ability able ..."; // 24 words
final passphrase = "";
final seed = bip39.mnemonicToSeed(mnemonic, passphrase: passphrase);
// seed is Uint8List(64)

final keyData = await ed25519_hd_key.ED25519_HD_KEY.derivePath(
  "m/44'/1337'/0'/0/0",
  seed,
);
```
