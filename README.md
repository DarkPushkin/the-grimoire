## 🔮 Quick Start

```bash
# 1. Install Hermes Agent
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc

# 2. Summon the Grimoire
git clone https://github.com/DarkPushkin/the-grimoire.git ~/the-grimoire

# 3. Speak the incantation
cd ~/the-grimoire && bash scripts/bootstrap.sh

# 4. Open the portal
hermes gateway run
```

Done! Full power of the grimoire in your hands (and Telegram) with ✅ buttons.
