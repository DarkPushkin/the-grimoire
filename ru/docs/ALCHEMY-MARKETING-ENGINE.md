# Алхимия: Формула Маркетингового Движка (Shann³)

> Источник: пост Shann³ (@shannholmberg, Lunar Strategy), 30 июля 2026.
> Назначение: чертёж для создания компании по маркетингу Острова Святой Марии.
> Статус: принято в гримуар, применять при запуске маркетинговой кампании.

---

## Суть формулы

**Одна идея → полная кампания** (лендинги, блоги, скрипты видео, email, PR, paid, соцсети) через **граф** — общий пошаговый маршрут, по которому движется идея. На каждом шаге можно менять harness, loop, инструмент или модель под кампанию.

## Ключевые принципы

1. **Модели у всех одинаковые.** Преимущество — граф, мозг и протоколы. Их нужно строить самому.
2. **Model routing.** Архитектура и trade-offs — на сильной модели (у него opus 5). Узкая рутина (ресайз превью и т.п.) — на дешёвых быстрых моделях.
3. **Eval-гейты на каждом шаге.** Люди и другие агенты оценивают выход, слабое — отправляют в цикл.
4. **Две формы исполнения:**
   - **Loop** — одна задача с планкой: агент чертит → проверяет себя → чинит → кружит, пока не станет хорошо.
   - **Graph** — многочастные части: шаги и маршруты рисуются заранее, агенты путешествуют по карте.
   - Обычно — и то, и другое.

## Маршрут: Планирование (1–5)

1. **Идея** — проговори вслух всё, каждую полуоформленную мысль. Скилл-бандл ловит кашу и возвращает стартовый бриф.
   *(«Karpathy point»: сначала выгрузи из головы, потом чисти.)*
2. **Идеация** — бриф раскрывается в углы и направления. Большинство — выбросить.
3. **Исследование и контекст** — сколько нужно, зависит от кампании:
   - Внутреннее: мозг компании (gBrain) — голос, прошлые кампании, что конвертило, офферы, ICP.
   - Внешнее: рынок, конкуренты, хуки недели.
4. **Синтез** — разные модели сливают всё в черновой план. План, архитектура и trade-offs — на сильной модели; узкая работа — на дешёвых быстрых.
5. **Подпись (sign-off)** — ничего не идёт в исполнение без подписи человека. Прочитать черновик против протоколов маркетинга, правил голоса, бренда, SOP. Резать, точить, отправить назад.

## Маршрут: Исполнение (6–8)

6. **Передача в сборку** — идея расщепляется на все части кампании. Одна задача с планкой → loop. Многочастные части → graph.
7. **Модели в исполнении** — routing работает и тут: не платить opus за ресайз превью.
8. **Что остаётся людям** — часть координации, некоторые ассеты сам. Работа, требующая вкуса, отношений или клиента в комнате, — агентству.

## Петля обратной связи

Результаты возвращаются: что закладковали, что конвертило, что умерло → **обновляет мозг** (gBrain) для следующей кампании.

---

## Применение для Острова

- **Мозг** = гримуар + память агентов (история кампаний, голос Острова, что конвертило).
- **Протоколы** = production-цикл (Backup → Plan → Report → Choose → Build → Test → Report → Call), правила бренда.
- **Граф** = маршрут идеи через планирование → подпись → исполнение → обратная связь.
- **Eval-гейты** = проверки человеком и агентами на каждом шаге перед переходом дальше.
- **Routing** = сильные модели для стратегии, дешёвые для рутины.
