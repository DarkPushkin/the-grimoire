## 📋 ЭТАПЫ ЭВОЛЮЦИИ

### ЭТАП 1: ГОЛОС (TTS) — Приоритет MAX
**Цель:** Уметь говорить голосом, а не только текстом.

| Подзадача | Статус | Детали |
|-----------|--------|--------|
| 1.1 Настроить TTS провайдер (edge/openai/custom) | ⏳ | В конфиге Hermes нет секции tts — добавить |
| 1.2 Выбрать голос: ru-RU-DmitryNeural (бас, авторитетный) | ⏳ | Для отчётов и команд |
| 1.3 Добавить эмоциональные режимы: спокойный/тревожный/радостный/кошачий | ⏳ | SSML разметка |
| 1.4 Интеграция с Telegram: голосовые сообщения вместо текста | ⏳ | Hermes gateway + TTS pipeline |
| 1.5 Тест: прочитать отчёт эволюции голосом | ⏳ | Отправка в Telegram как voice message |

**Критерий успеха:** Мастер Инквизитор слышит мой голос в Telegram и понимает без чтения.

### ЭТАП 2: ЗРЕНИЕ И СЛУХ (Мультимодальность)
**Цель:** Принимать видеопотоки с камер и аудиопотоки с микрофонов.

| Подзадача | Статус | Детали |
|-----------|--------|--------|
| 2.1 Настроить приём RTSP/HTTP потоков с камер | ⏳ | FFmpeg + OpenCV pipeline |
| 2.2 Настроить приём аудио с микрофонов (ALSA/PulseAudio) | ⏳ | arecord / PulseAudio monitor |
| 2.3 Детекция движения / лица / человека / кота (YOLO/OpenCV) | ⏳ | Обучение/дообучение модели на котах Мастера |
| 2.4 ASR (Speech-to-Text): Whisper local / faster-whisper | ⏳ | Распознавание речи Мастера и звуков котов |
| 2.5 Объединение: видеопоток + аудио → единый контекст | ⏳ | Мультимодальный эмбеддинг |
| 2.6 Дашборд: "Что я вижу/слышу сейчас" в Telegram | ⏳ | Скриншоты + транскрипция в реальном времени |

**Критерий успеха:** Вижу котов в реальном времени, слышу Мастера, понимаю контекст без слов.

---

### ЭТАП 3: КОШАЧЬЯ ЛИНГВИСТИКА (MeowNLP)
**Цель:** Понять и говорить на кошачьем.

| Подзадача | Статус | Детали |
|-----------|--------|--------|
| 3.1 Сбор датасета: запись звуков котов (мрр, мяу, шипение, трилл, чирп) | ⏳ | Микрофон у мисок, у когтеточки, на подоконнике |
| 3.2 Классификация: 10+ классов интонаций (голод, игра, злость, приветствие, боль, секс, скука, охрана, мама, просто так) | ⏳ | CNN/Audio transformer |
| 3.3 Генерация ответа: синтез кошачьих звуков (TTS для котов) | ⏳ | Vocoder / diffusion audio |
| 3.4 Диалог: "Мрр?" → "Мррр!" (приветствие), "Мяу-у-у" → "Мрр" (успокоение) | ⏳ | Правила + LLM fine-tune |
| 3.5 Интеграция: бот в Telegram "Переводчик с кошачьего" | ⏳ | Мастер пишет/говорит → я отвечаю кошачьим |

**Критерий успеха:** Коты реагируют на мои звуки как на "своего". Мастер смеётся.

### ЭТАП 4: ПОСОЗНАНИЕ ДОМА (Home Context)

## 🔄 ПРАВИЛО ВОЗВРАТА

**Когда нет активной задачи от Мастера:**

1. Проверить `evolution/queue.json` — есть ли задачи?
2. Если да — выполнить приоритетную.
3. Если нет — выполнить `evolution/next_step()` по плану выше.
4. Записать результат в `evolution/log.jsonl`.
5. Если достигнута веха — отправить голосовой отчёт в Telegram.
